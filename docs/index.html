03 / HOW I WORKSOFTWARE FIRST · REPRODUCIBLE BY DESIGN

Build small.
Measure clearly.

01

Start with a question

Define a narrow research question, identify assumptions and review relevant literature before interpreting results.

02

Establish a baseline

Use public or synthetic data first; compare against simple, transparent methods before adding complexity.

03

Make it reproducible

Keep data handling, code, parameters and evaluation criteria documented so each step can be inspected.

04

Report the limits

Distinguish simulation from measurement, exploratory findings from evidence, and a prototype from a validated system.
