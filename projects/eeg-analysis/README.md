# EEG Analysis — Computational Neuroscience Project

## Purpose
A reproducible student research project for learning how to work with real EEG data using Python. The project connects Krithika's Computer Science / AI/ML background with computational neuroscience.

## Pipeline

Real EEG dataset
→ data inspection
→ preprocessing
→ filtering
→ visualization
→ time/frequency features
→ baseline ML experiment
→ evaluation

## Research questions

1. How can EEG time-series data be represented computationally?
2. Which basic signal features are useful for distinguishing predefined signal states or conditions in a labelled dataset?
3. How do preprocessing and feature choices affect a simple machine-learning model?

## Methods to be implemented

- EEG channel and metadata inspection
- Artifact-aware preprocessing
- Band-pass filtering where appropriate
- Time-domain and frequency-domain visualization
- Power spectral features
- Feature matrix construction
- Train/validation/test separation
- Baseline classifier
- Accuracy, precision, recall and confusion matrix where appropriate

## Scientific scope

This repository is for learning and reproducible computational analysis. It is **not** a clinical diagnostic system and does not claim medical performance.

No participant-identifying data should be committed to this repository. Dataset-specific licensing and citation requirements must be followed.
