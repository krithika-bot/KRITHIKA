# Project Lab Website

Static, self-contained concept site for the Himalayan Soldier Safety & Load Monitor. No external JavaScript library, image host, analytics, or network connection is required.

## Run locally

From the `site/` folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser. The 3D-style effects are CSS/SVG illustrations; the exploded/assembled toggle and rotation control work locally.

## Evidence and image labels

The drawings are original vector concept illustrations. They are **not photographs of real hardware** and do not imply that a sensor, enclosure, strap, or load-cell assembly has been built. Replace them with dated, genuine prototype photos only after the physical build exists.

All hardware dimensions, sensor placements, and attachment locations are proposed and untested. See `../docs/hardware_and_system_plan.md` and `../docs/evidence_register.md`.
