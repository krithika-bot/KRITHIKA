# Complete project documentation: Neural Mass Model

## 1. Project summary

This project implements and explores the classical two-population Wilson–Cowan model of excitatory and inhibitory neural activity. It is designed as a compact computational neuroscience learning project: begin from a published equation, make the parameters explicit, numerically integrate the system, and inspect how input and coupling choices change the simulated dynamics.

**Current level:** reproducible software simulation and exploratory one-factor sensitivity study. It is not a data-driven neuroscience experiment, a biological validation, or a clinical model.

## 2. Research question

How do constant external excitatory drive and selected excitatory/inhibitory coupling coefficients change population activity, oscillation frequency, and the presence of a resolved limit cycle in the Wilson–Cowan two-population model?

## 3. Core concept

The model represents one local neural population with two aggregate state variables: `E(t)` for excitatory population activity and `I(t)` for inhibitory population activity. Each population receives nonlinear input through a shifted sigmoid response. Excitatory and inhibitory coupling combine with the external inputs `P` and `Q`; activity and refractory terms bound the modeled response.

The system is low-dimensional and deterministic. Its purpose here is to make population-level interactions and parameter sensitivity inspectable. No individual neurons, anatomy, EEG signals, or subjects are modeled.

## 4. Model equations

The implementation follows the time-coarse-grained equations in Eq. 12 of Wilson and Cowan (1972):

```text
τE dE/dt = -E + (kE - rE E) SE(c1 E - c2 I + P)
τI dI/dt = -I + (kI - rI I) SI(c3 E - c4 I + Q)
```

The shifted logistic functions and maxima are:

```text
SE(x) = 1 / (1 + exp(-aE (x - θE))) - 1 / (1 + exp(aE θE))
SI(x) = 1 / (1 + exp(-aI (x - θI))) - 1 / (1 + exp(aI θI))
kE = 1 - 1 / (1 + exp(aE θE))
kI = 1 - 1 / (1 + exp(aI θI))
```

Thus `SE(0)=SI(0)=0`; `E` and `I` are dimensionless activity variables and time is in milliseconds. These are the coarse-grained dynamics, not the paper's earlier integral/delay equations.

The primary source is Wilson and Cowan (1972), *Excitatory and Inhibitory Interactions in Localized Populations of Model Neurons*, *Biophysical Journal*, 12(1), 1–24. Eq. 12 gives the model form and the shifted logistic is described in Eq. 15. Figure 11 gives the baseline parameter set and shows a limit-cycle example for `P=1.25` with `τ=8 ms`.

## 6. Data and evidence provenance

**Dataset:** none. There is no downloaded or included EEG, animal, human, or clinical dataset. The CSV files are outputs generated by the deterministic model from the checked-in source code and configuration. Their provenance is recorded in `results/run_info.json`.

The model source is the paper cited above. This project is a computational reproduction of one published qualitative example plus a limited parameter scan; it is not a complete reproduction of the article.

## 7. Implementation and tools

- `src/wilson_cowan.py`: immutable parameter configuration, shifted logistic responses, differential equations, RK4 stepper, simulation loop, and trajectory metrics.
- `scripts/run_analysis.py`: baseline run, drive and coupling sweeps, timestep sensitivity, metadata, CSVs, and vector figure generation.
- Python 3.10+ standard library only; no model or plotting dependencies are required.
- CSV for numeric evidence, JSON for run provenance, and SVG for figures.
- The run recorded in `results/run_info.json` used Python 3.12.10.

## 8. Protocol and analysis

1. Initialize the baseline at `(E,I)=(0.02,0.02)` and integrate 2,000 ms using RK4 with a 0.1 ms timestep.
2. Compare the last 500 ms of the baseline with the qualitative limit-cycle trajectory in Figure 11.
3. Sweep `P` from 0.80 to 2.50 at 0.05 increments. Integrate each setting for 10,000 ms and summarize the final 1,000 ms.
4. At `P=1.25`, vary `c2`, `c3`, and `c4` one at a time, holding the other parameters at baseline. Integrate each setting for 4,000 ms and summarize the final 1,000 ms.
5. Detect E local maxima in each summary window. Estimate frequency as 1,000 divided by the mean inter-peak interval in milliseconds.
6. Label `limit_cycle` only when E peak-to-peak amplitude is at least 0.01 and at least three peaks are detected; a lower-amplitude trace is labeled `steady_state`. The 0.01 threshold is an analysis convention to suppress numerical noise, not a mathematical stability criterion.
7. Repeat the baseline with RK4 steps of 0.2, 0.1, and 0.05 ms; compare amplitude and peak-interval frequency. Repeat the 0.1 ms baseline to check deterministic replay.

## 9. Main results

- Baseline `P=1.25`: E amplitude **0.16710**, I amplitude **0.17273**, mean E **0.15945**, estimated frequency **25.02 Hz** and period **39.97 ms**.
- Drive scan: resolved cycles appear at the sampled `P=1.10` and remain through `P=1.85`; `P=1.90` is below the declared amplitude threshold after the 10-second run. Within the resolved-cycle range, frequency rises and mean E increases while oscillation amplitude shrinks.
- Coupling scan: the baseline cycle is sensitive to `c2`, `c3`, and `c4`. For example, `c3=12` is below the threshold, `c3=15` produces the baseline cycle, and `c3=18` is again below the threshold. Increasing sampled `c4` from 3 to 5 takes the system from amplitude 0.16710 to the steady-state classification.
- Timestep sensitivity: frequencies are 25.0227, 25.0209, and 25.0209 Hz at 0.2, 0.1, and 0.05 ms; amplitude differences against 0.05 ms are below 0.001% for all three settings.
- An exact repeated run returns the same baseline summary.

Detailed tables and figure files are listed in [the results note](docs/RESULTS.md).

## 10. Reproducibility

From this directory, run:

```bash
python3 scripts/run_analysis.py
```

To choose an output directory:

```bash
python3 scripts/run_analysis.py --out /path/to/output-directory
```

The script rewrites the evidence files deterministically apart from the `generated_at_utc` metadata timestamp. No random seed is needed because the model is deterministic. The exact parameters, integration durations, timestep, software version, source, script hash, and data status are recorded in `results/run_info.json`; `results/checksums.sha256` hashes the generated outputs.

## 11. Limitations

- Two aggregate variables cannot describe spatial structure, individual cells, synaptic detail, network connectivity, or whole-brain dynamics.
- The published example's parameters are illustrative and are not estimated from measurement.
- One-factor scans do not capture parameter interactions or prove parameter identifiability.
- The finite grid and threshold only operationally classify oscillations; they do not locate a precise bifurcation.
- Matching a plotted simulation qualitatively is a software/model check, not validation against biological recordings.
- No real EEG or other empirical signals were analyzed. Nothing here supports diagnosis, treatment, or claims about a person.
