# Methods and implementation decisions

## Scope

This is a deterministic software study of one local excitatory/inhibitory population pair. The source is the time-coarse-grained Wilson–Cowan model in Eq. 12 of Wilson and Cowan (1972), not a newly proposed neural model. No experimental dataset is used.

## Equations

```text
τE dE/dt = -E + (kE - rE E) SE(c1 E - c2 I + P)
τI dI/dt = -I + (kI - rI I) SI(c3 E - c4 I + Q)

SE(x) = sigmoid(aE (x - θE)) - sigmoid(-aE θE)
SI(x) = sigmoid(aI (x - θI)) - sigmoid(-aI θI)
kE = 1 - sigmoid(-aE θE)
kI = 1 - sigmoid(-aI θI)
sigmoid(z) = 1 / (1 + exp(-z))
```

The shift makes each response zero at zero net input, as described in the source paper. The refractory factors use `rE=rI=1` for the Figure 11 parameterization.

## Baseline parameterization

| Parameter | Value | Interpretation |
|---|---:|---|
| `c1` | 16 | Excitatory input to the excitatory population |
| `c2` | 12 | Inhibitory input to the excitatory population |
| `c3` | 15 | Excitatory input to the inhibitory population |
| `c4` | 3 | Inhibitory input to the inhibitory population |
| `aE`, `θE` | 1.3, 4 | Excitatory response slope and threshold |
| `aI`, `θI` | 2, 3.7 | Inhibitory response slope and threshold |
| `rE`, `rI` | 1, 1 | Refractory/activity feedback coefficients |
| `τE`, `τI` | 8 ms, 8 ms | Population time constants shown with Figure 11 |
| `P`, `Q` | 1.25, 0 | External excitatory and inhibitory drives |

The four coupling values, response parameters, refractory coefficients, drive `P`, and time constant are taken from Figure 11 in the paper. `Q=0` is used for the constant-stimulation example.

## Numerical integration

- Solver: classical explicit RK4, implemented directly in `src/wilson_cowan.py`.
- Baseline: 2,000 ms duration, 0.1 ms step, initial state `(E, I)=(0.02, 0.02)`.
- Drive scan: `P=0.80` to `2.50` in 0.05 increments; 10,000 ms per point; the last 1,000 ms are summarized.
- Coupling scans: vary `c2`, `c3`, or `c4` individually at `P=1.25`; 4,000 ms per point; the last 1,000 ms are summarized.
- Frequency: mean interval between detected local maxima of `E` in the summary window. Frequency is omitted when E peak-to-peak amplitude is below 0.01.
- Oscillation classification: `limit_cycle` requires E peak-to-peak amplitude at least 0.01 and at least three detected peaks; otherwise a below-threshold trace is labeled `steady_state`. This is an operational display threshold, not a mathematical bifurcation test.
- Timestep sensitivity: baseline repeated at 0.2, 0.1, and 0.05 ms; 0.05 ms is the reference for percentage differences.
- Determinism: same baseline configuration is run twice and output summary values compared exactly.

## Tools and reproducibility

The code uses Python 3.10+ standard library only. CSV, JSON, and SVG outputs are generated by `scripts/run_analysis.py`; no package installation is needed.

```bash
python3 scripts/run_analysis.py
```

`results/run_info.json` records parameters, duration, timestep, software version, source, data status, and numerical checks. `results/` contains the generated numerical tables and figures. No random numbers are used.

## Provenance and evidence boundaries

All numeric outputs in this package are generated by the checked-in simulation code from the equations and parameters above. There is no external data source because no dataset is used. The original paper is the source for the model form and Figure 11 parameter values; the results here are a small computational reproduction and one-factor exploration, not a replication of all paper analyses.
